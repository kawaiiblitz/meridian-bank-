Development branch: development
Created off: main

The development branch is named `development` and is created off `main` (the
clean environment that changes are promoted back into).

Branch-creation call (committed in infra/create_dev_branch.sh):

    git checkout -b development main        # git: create `development` off `main`

    databricks postgres create-branch projects/meridian-bank development \
        --json '{"spec": {"source_branch": "projects/meridian-bank/branches/production"}}'
                                            # Lakebase: `development` off the clean branch

Branches:
  main / production  = clean environment (promote target)
  development        = iteration branch off main (all Build 1 work happens here)
  forecasting        = throwaway branch (ttl 7d) for what-if scenarios

Changes committed on development were promoted into main via merge / PR #1
(see git_history.txt and pr_merge_evidence.txt).
